# 使用说明

本包包含100条中国乡村适老化案例、16条条件化经验规则、67个来源页面和12条拟制测试情境。整理截至2026-09-09。

## 文件

- rural_age_friendly_100.xlsx：概览、案例库、来源、蒸馏规则和字段说明，可筛选阅读。
- casebook.md：100条完整案例卡及出处总表。
- SKILL.md：可供目标平台适配的技能草案，尚未完成安装、训练或实测。
- references/cases.jsonl：一行一个案例，UTF-8编码。事实、经验和边界分栏。
- references/rules.jsonl：一行一条条件化经验规则。
- references/sources.json：来源标题、机构、日期、原始链接及对应案例。
- references/schema.json：案例字段含义。
- references/source_groups.json：62个关联组，训练/评测按组分开。
- evals.jsonl：12条拟制评测情境，不能计作真实案例。
- validation_report.json：本地结构检查结果，不代表事实现场核验。

## 重要限制

范围为广义乡村适老化，不是100个建筑竣工项目。案例包括住宅和村庄空间、旧建筑改用、助餐照护、互助安居及运营。明确标出城乡混合、县域与乡镇域案例；这些都不能冒充单村项目。

报道年份：2022年3条、2023年10条、2024年19条、2025年44条、2026年24条。87条报道来自2024—2026年，不表示87个项目在这三年建成。

读取深度：65条A类已读网页正文，35条B类仅获得检索结果文本。B类在进入正式训练前宜补读原文。A/B不是效果质量评级。

R020为反面；R010报道时正在实施；R071只确认已开展评估。R054、R080选用页面日期与URL年份不一致；R098正文相对时间存在疑点。所有案例均未现场复核，也不是独立效果评估。

蒸馏经验是分析推论，不是工程规范、医疗操作、现行法律政策或补贴承诺。尺寸、价格、权限、政策资格等用于具体项目时需另行核实。不要以年龄代替功能评估，不要以设备数量代替效果。

本包仅包含短篇事实概括和原创分析，不包含来源新闻全文；出处内容及相关图片的版权仍归原权利人，正式模型训练需自行审查数据使用权限。

## 建议流程

先阅读SKILL.md与16条规则；按案例主题、老人能力与场景检索；引用事实时保留case_id及source_url；B类补读原文；按leakage_group做训练/评测划分；人工审核拟制评测的预期行为；最后在目标技能环境测试引用及拒绝编造的稳定性。

未提供已训练模型、训练权重或平台安装结果。
