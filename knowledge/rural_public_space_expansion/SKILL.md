# 乡村公共空间适老化参考分析

## 数据与边界

读取 `manifest.json` 后再读取 `data/cases.jsonl`。本包实际100条新增参考卡，未完成1,000+条要求；47条为国内乡村核心。其他条目是国内城乡／城市或国外参考，不是已证实的中国乡村适老化成果。

本包不是已经过人工验收的监督微调集或多模态训练集。26条有远程图URL，74条尚缺可用图片URL，没有离线项目照片，图像训练许可未确认。A仅表示读取过相关正文片段，B为元数据／检索摘要。使用前保留这些标记，不把它们改写成“已核验成功案例”。

## 工作流程

1. 根据任务确定日常活动、场地类型、老人能力、气候地形、预算与运营主体。信息未给出时标为待核，不替用户编造。
2. 优先检索 `scope_group=国内乡村核心`，再选城乡与国外迁移参考。用 `source_facts` 识别真实做法，用 `age_friendly_inference` 和 `transfer_boundary` 做条件对照。
3. 每项建议至少给出一个案例ID及原始来源URL。对照案例的适用条件和风险，不只摘取形态、材料与图片。
4. 核图时使用 `images` 中实际记录的URL及原页面。空数组表示缺图。`image_reading_focus` 是待观察清单，不能当作已经从图片看到的事实。
5. 输出事实、迁移建议、不可照搬条件、待核问题和来源。后评价使用 `suggested_evaluation`，明确它是拟采集的数据，不是原项目成效。
6. 正式训练前逐条人工审核，确认来源、场景分类、建成状态、图片对应关系及适用许可。工程尺寸、医疗效果和现行规范另查，不能从宣传图推定。

## 输出结构

项目ID与名称 → 地点及原始场景 → 报道年／完成年 → 来源事实 → 空间组织 → 适老化迁移推论 → 不适用条件 → 运营待核 → 建议评价 → 配图与图注状态 → 出处。

对无直接证据的字段使用“未核实”。对图片无法加载的情况提供原始来源入口并注明缺口，不以别的项目照片或生成图替代。

## 去重与测试

按独立场地／工程或明确命名计划计数，源文章、语言版本、分期、分区、照片和规则不另计案例。旧批次排除记录在 `references/prior_case_exclusion_register.json`。本包同一项目名、地名与原链接经排重未发现旧项目重复，但没有地籍级唯一性确认。

同一上位计划中的不同场地可以保留为独立记录，但训练／测试按 `case_family` 分组。不要把丰梧季两场地或同一套NParks计划随意拆到两侧制造“独立泛化”表现。

执行 `python tools/validate.py` 检查条数、必填字段、精确链接重复与未完成图像状态。它不能替代实体去重和现场核验。

## 必须避免的错误

把原型或未建成方案当成建成；把有坡道当成全程无障碍；把装置承载能力当成老人可用性；把取消护栏当成适老通则；把药用植物当成医学疗效；把获奖、参观人数或满意感当成可归因成效；把源图片公开展示当成已取得模型训练许可；把100条参考卡标成1,000条完整图文库。
