# 乡村与公共空间适老化参考库

本次实际新增100条参考卡：中国88条，国外12条；其中47条国内乡村核心、41条国内城乡及城市迁移、2条国外村镇、10条国外城市迁移。

**未完成事项：未达到1,000+条；未给每条配齐图片。**26条有远程图片URL，74条没有可用图片URL。2条至少一图目视查看；没有离线项目照片。源图片训练许可均未确认。A类76条为相关正文片段已读，B类24条为摘要／元数据；全部需进一步复核。

## 文件

`case_reader.html`：可搜索、筛选的本地浏览页。所有文字数据嵌入HTML；远程照片需联网、点击加载，并可能受失效或跨站限制影响。

`public_space_cases_100.xlsx`：9个工作表，包含概览、案例目录、空间分析、运营评估、图源状态、Sources、蒸馏规则、旧库排除表、字段说明。

`casebook.md`：完整文字案例卡及逐案来源、图源入口。没有以另一项目照片填补缺图。

`data/cases.jsonl`：一行一个案例，事实与推论分开，保留证据状态。用于检索知识库或进一步人工整理，不是已审核的监督训练集。

`references/`：102条来源记录、26条远程图像记录、20条蒸馏规则、字段说明及旧100条的排除登记。

`SKILL.md`：检索、迁移分析、证据处理和避错流程草案，未在目标技能平台实测。

`tools/validate.py`：离线校验数据完整性、精确重复及图像状态。无第三方依赖。`python tools/validate.py`。

`tests/evaluation_prompts.jsonl`：拟制的技能测试情境与判据，不计入案例数量；不是实际访谈或项目事实。

## 计数和证据

同项目的多节点、多语言或转载不另计。部分同计划但独立场地保留案例并设关联组。已用名称、地点和原链接与旧100条比对，未发现同一项目；未做现场地籍级排重。

报道／页面年份和竣工／开放时间分开。30条可确认报道／页面年为2024—2026；28条报道／页面年未可靠确认，留空。其余包含较早参考，不声称全部近年建成。

除“来源支持的做法”外，空间摘要、适老化经验、运营问题和评价方法是分析归纳。没有虚填坡度、宽度、成本、老人数量或跌倒下降比例。公开源文的叙述也可能需要复核。

## 图片和训练

图像URL的存在、浏览器能显示、图像与项目对应、人工读图和训练使用许可是不同检查项，本包不混同。未下载项目照片，不向使用者转授任何源图片权利。用于模型图像训练前，需要另核实际权利方及许可；用于检索型skill时也要保留出处与证据状态。
